3.1.32 सनाद्यन्ता धातवः
संधि विच्छेद : सनादी अंता धातवः
अनु वृत्ती : none
Language Meaning : सन् आदी अंता are धातु 

Literal Meaning
align pull till roll connects pull tumbi upto, carry untill tumbi wave tight

Meaning
sraighten pull before inward wave joins upto tumbi, carry before wave tightens tumbi, i.e. complete "carry" activity before incoming tide

Comment
Logical conclusion from this point on is to find out when tide is going to come again.
I believe there must be many thousands, if not lakhs years before that step actually occurred.
