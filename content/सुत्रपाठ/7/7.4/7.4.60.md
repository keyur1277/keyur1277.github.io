हलादिः शेषः
[[7.4.59]] - [[7.4.61]]
SV: हल्-आदिः  शेषः
AV:  अभ्यासस्य 
Language Meaning:  Only the first हल् letter from अभ्यास is retained, rest all हल् letters are removed.

Literal meaning 
[[अभ्यास]] - here stand connect untill gather
हल् = tight soft
आदिः  = untill roll inward exist 
शेषः = into long tip

Literal meaning of linguistic interpretaion:
stand here and connect while it continues, tight into soft till rolling exists, into long tip/pointed

Meaning explained: originally this meant keep pulling till it lasts. 
Later it got interpreted as when something is done repeatedly, mention first हल् twice to indicate this - "keep pulling till it lasts" sense. reduplicated हल् is a do while loop.
