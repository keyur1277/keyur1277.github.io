अर्तिह्रीव्लीरीक्नूयीक्ष्माय्यातां पुङ्णौ
SV:  अर्तिह्रीव्लीरीक्नूयीक्ष्माय्याताम् ( षष्ठी-बहुवचनम् ) , पुक् ( प्रथमा-एकवचनम् ) , णौ ( सप्तमी-एकवचनम् ) 
AV: none
status: partly
Language Meaning: The augment पुक् (प्) is added to the roots १. ऋ २. ह्री ३. व्ली ४. री ५. क्नुय् ६. क्ष्माय and to a root ending in long आ when the affix णि (the Causative) follows.

literal  meaning of linguistic interpretation
after following activities and after an activity that says "up to" in the end, if next instruction is push below णि, consider "verb(footing) maneuver" before णि

[[ऋ]] = "superior + push below" is to be read as "superior verb(footing) maneuver push below"
[[ह्री]]  = "exists water/blood below push below" is to be read as "exists water/blood below verb(footing/rope) maneuver push below"
[[व्ली]] 
[[री]] = "blood/bloody push below" is to be read as "blood footing above stone push below"
[[क्नूय्]] = "maneuver pull up join below" is to be read as "maneuver pull up join below footing up/above maneuver push below"
[[क्ष्माय्]]   = "aim inside till join below" is to be read as "aim inside till join below footing above/up maneuver" when followed by push below
