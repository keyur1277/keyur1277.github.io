# तृतीय अध्याय प्रथम पाद 
3.1.1 प्रत्ययः [[प्रत्ययः]]
संधि विच्छेद : none 
अनु वृत्ती : none 
Meaning:  naturalized connection
3.1.2 परश्च
संधि विच्छेद: परः (1.1) च (अव्यय)
अनुवृत्ति : none 
Meaning: After
3.1.3 आद्युदात्तश्च
संधि विच्छेद : आदी (1.1) उदात्त (1.1 ) च (अव्यय)
अनुवृत्ति : none 
Meaning : beginer is upper
3.1.4 अनुदात्तौ सुप्पितौ
संधि विच्छेद : अन उदात्त (1.2) सुप पीत (1.2)
अनुवृत्ति : none 
Meaing: Remove upper for सुप and पीत. i.e. not upper in case of  सुप and पीत
