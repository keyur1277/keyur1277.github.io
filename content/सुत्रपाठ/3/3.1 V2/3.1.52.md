अस्यतिवक्तिख्यातिभ्योऽङ्
[[3.1.51]] - [[3.1.53]] 
SV:  अस्यति-वक्ति-ख्यातिभ्यः ( पञ्चमी-बहुवचनम् ) , अङ् ( प्रथमा-एकवचनम् ) 
AV: च्लेः [[3.1.44]] 
Language Meaning:  For the verbs असुँ (क्षेपणे), वच्, and ख्या, the च्लि-प्रत्यय is converted to अङ्.

Literal meaning of linguistic interpretation (अलौकिक का लौकिक अर्थ)
[[अङ्]] here outside substitutes च्लि knotting sand / inward walk sand for
अस्यति = [[असु]] + [[श्यन्]] + [[तिप्]]  = here align outward + javeline join noose + float below  footing
वक्ति = [[वच्]] + [[शप्]]  (लुक)  + [[तिप्]]  = wave encircle + mooring post + float below footing
ख्याति = [[ख्या]] + [[शप्]]  (लुक) + तिप् =  till hollow join + + mooring post + float below footing
