3.3.90 यजयाचयतविच्छप्रच्छरक्षो नङ् 
SV :  यज-याच-यत-विच्छ-प्रच्छ-रक्षः (5/1) नङ् 
AV: कृत् 
 Language meaning : नङ्  is suffix to indicate doer or instrument 

 Literal Meaning
 यज् join open 
 याच  = join untill knot
[[यत्]] = join tumbi  
विच्छ = waving inward repeat many
प्रच्छ = Reed repeat many 
रक्षो  =  water/blood from aim 
नङ् = pull outside
