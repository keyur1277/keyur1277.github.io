अभ्यासे चर्च 
[[8.4.53]] - [[8.4.55]]
SV:  अभ्यासे चर्च 
AV: झलाम् जश् 
Language meaning: A झल् letter present in an अभ्यास is converted either to a जश् letter or a चर् letter as appropriate.

Literal meaning of linguistic interpretation
into [[अभ्यास]]  = into here stand join till gather (lasts)

[[ख]] [[क]] = hollow is to be read a maneuver 
[[फ]] [[प]] = footing-less is to be read as footing/rope/leg
[[छ]] [[च]] = many/drill/loose is to be read as again/circle/knot 
[[ठ]] [[ट]] =  low ground is to be read as basket/टीला 
[[थ]] [[त]] = platform/step up us to be read as float/that 
[[घ]] [[ग]] = hunted is to be read as live  
[[झ]] [[ज]] = vibrating/hesitant is to be read as wide/jump/open 
[[ढ]] [[ड]] = useless is to be read as fear/predator 
[[ध]] [[द]]  = carry/hold/bear is to be read as give/roll 
[[भ]] [[ब]] = steady/standing/unbound is to be read as bound

comment- The idea is something like this - if act is to be done again and again and if it is said to be घ hunted at the begining itself; you need to read as living. If act is to be done again and again, and it is said to be empty at the begining you need to read as maneuver/hand. because the start state/action of maneuver/living is prerequisite to arrive at empty/hunted at the end.
