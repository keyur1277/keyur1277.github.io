विज इट्

SV:  विजः ( पञ्चमी-एकवचनम् ) , इट् ( प्रथमा-एकवचनम् ) 
AV: ङित् [[1.2.1]] 
Language: from विज्, ङित्, इट्

Literal meaning of linguistic interpretation (अलौकिक का लौकिक अर्थ)
[[विज्]]  = from detach (object(wave) object(opening)
इट् - below coracle is interpreted 
ङित् = then instruction is understood to be "outside /periphery" 

meaning explained
While detaching by wavering and widening, if below coracle is assumed, instruction is to be understood to be "outside/periphery like".
